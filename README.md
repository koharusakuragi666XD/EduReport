# EduReport

EduReport es una aplicación de escritorio desarrollada en Java Swing para administrar aulas, alumnos e incidencias escolares.

## Funciones principales

- Registrar y administrar aulas.
- Registrar alumnos.
- Registrar reportes de conducta.
- Importar alumnos desde archivos Excel.
- Generar reportes en PDF.
- Guardar la información en MongoDB.

## Tecnologías

- Java
- Java Swing
- MongoDB
- Maven
- Apache POI
- iTextPDF

## Estado del proyecto

Versión 1.0 funcional desarrollada como anteproyecto escolar.
